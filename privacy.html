개인정보처리방침

절세 장부 (안드로이드 앱 kr.sks.taxledger) · 시행일 2026-10-17

1. 모으는 정보와 쓰는 곳

  • 카드 승인 문자: 사업용 카드 승인 모양의 문자에서 날짜·금액·가게 이름만 읽어 장부에 적습니다. 카드 승인이 아닌 문자는 읽은 즉시 버리고 저장하지 않습니다.
  • 영수증 사진·PDF·캡처: 사용자가 찍거나 고른 것만, 글자 읽기(OCR)를 폰 안에서 한 뒤 사용자의 구글 드라이브에 올립니다.
  • 장부 내용: 결제 내역, 메모, 계정과목, 신고 준비용 설정(과세유형·개업일 등).

2. 보관 위치

모든 장부와 증빙은 사용자 본인의 구글 드라이브 "절세장부" 폴더에만 저장됩니다. 앱은 구글 드라이브 권한 중 drive.file(이 앱이 만든 파일만 접근)만 사용하며, 드라이브의 다른 파일은 보거나 읽지 않습니다.

인터넷이 끊겼을 때 기록을 잃지 않도록 장부 글자 사본 하나를 앱 전용 공간에 둡니다. 사진·PDF는 폰에 남기지 않습니다.

3. 제3자 제공

개발자 서버가 없으며, 어떤 정보도 개발자나 제3자에게 보내지 않습니다. 광고·분석·추적 도구를 쓰지 않습니다. 데이터는 사용자의 폰과 사용자의 구글 드라이브 사이에서만 오갑니다.

4. Google 사용자 데이터

이 앱이 Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 드라이브 접근은 사용자가 만든 장부·증빙 파일을 저장하고 불러오는 데만 씁니다.

5. 삭제

구글 드라이브의 "절세장부" 폴더를 지우면 모든 기록이 지워집니다. 앱을 지우면 폰의 장부 사본도 함께 지워집니다. 구글 계정 설정 › 보안 › 타사 앱 액세스에서 이 앱의 드라이브 권한을 언제든 끊을 수 있습니다.
